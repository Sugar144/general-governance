# General Governance Roadmap

This roadmap is a compact planning surface for portfolio/state integrity. It does not replace release manifests, immutable release evidence, framework contracts, or Owner decisions.

## Current stage — rc.7 Owner disposition

`0.1.0-rc.7` is integrated on `main` as an immutable release candidate and is pending explicit Project Owner disposition.

Completion condition:

- the Owner records the disposition of the exact rc.7 candidate.

## After disposition

If rc.7 is accepted, any tag, GitHub Release, deployment, adopter upgrade, or adopter mutation remains a separately authorized effect and must follow the applicable release/adoption controls.

If rc.7 requires correction, correction work must be separately authorized and preserve the immutable rc.7 evidence and lineage.

## Planning rule

Material changes to phase structure, sequence, dependencies, deferral, cancellation, or newly defined future work must update this roadmap in the same pull request and declare `Project-State-Impact: roadmap` or `both`.
